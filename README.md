一份用来构建 **「勇哥餐饮.skill」** 的开源语料库。把抖音/B站「勇哥餐饮创业说」（梁朝勇）数百场连麦中沉淀下来的**方法论、案例、金句、街景观察清单**，整理成结构化、可被 LLM/Skill 直接调用的 Markdown 知识库。

不是娱乐项目（虽然确实很乐）。**真正的目的是：让任何一个想开餐饮店的普通人，在掏钱之前，先被勇哥（的影分身）骂醒一次。**

---

## 它能干什么

- 🪞 **餐饮体检**：输入你店里的营业额、毛利率、房租、人工，**5 秒算出保本线**，告诉你"还有救还是关了吧"
- 🧭 **开店决策**：走完勇哥的"开店五步法"，用数据回答**要不要开 / 开在哪 / 开什么 / 投多少**
- 🏚️ **快招识别**：你只需说出"加盟品牌名 + 总部城市 + 加盟费"，立刻拿到一份**快招风险评分**
- 📸 **360 度转一圈**：上传/拍摄一段店门口街景，AI 用 12 个观察点逐一打分（门头宽度、台阶、阴阳街、转让密度、竞品环境……）
- 📚 **案例匹配**：你的情况像谁？是"脸盆姐"还是"七层奶茶大厦"？从 30+ 真实翻车案例里拉出最像你的那一个
- 🎤 **勇哥嘴替**：用勇哥的语气、节奏、口头禅给你诊断结论。该劝退就劝退，该骂就骂，该吸氧就吸氧

## 快速开始

### 我只想看勇哥的方法论
直接读 [`corpus/02-诊断SOP.md`](./corpus/02-诊断SOP.md) 和 [`corpus/03-选址方法论.md`](./corpus/03-选址方法论.md)，**这两份是全部精华**。

### 我想用它来开店做决策
1. 先看 [`corpus/05-品类与赛道.md`](./corpus/05-品类与赛道.md) ——别一头扎进"中年破产四件套"
2. 用 [`skill/保本线计算器.md`](./skill/保本线计算器.md) 把数算清楚
3. 用 [`skill/街景观察清单.md`](./skill/街景观察清单.md) 拿手机去你看上的铺子门口对照打分
4. 看完 [`cases/`](./cases/) 里跟你预算/品类相近的失败案例，**别成下一个**

### 我想基于它编写 skill / Agent

- 角色扮演 / 风格迁移 → 重点读 `corpus/06-金句与话术.md` + `skill/风格指引.md`

## 使用示例（设想中的 skill 交互）

### 场景 1：体检已开门店

```
用户：勇哥救救我，我开了家奶茶店在县城综合体三楼，每天卖 800

skill：（自动调用 corpus/02-诊断SOP.md 第一步）
       哥们儿你先告诉我几个数：
       1. 总共投了多少钱？哪儿来的？
       2. 月房租多少？人工几个人？
       3. 毛利率多少？（不知道就告诉我食材一天用多少钱）
       4. 旁边有没有蜜雪、瑞幸、霸王茶姬？

用户：投了 35 万，10 万贷款；房租 8000 一个月；2 个员工 4500 一个；
     毛利率不知道...食材一天用 250 左右；旁边一楼有蜜雪。

skill：等会儿我给你算一下。【调用 skill/保本线计算器.md】
      ━━━━━━━━━━━━━━━━━━━━
      你的毛利率：(800-250)/800 = 68.75%（饮品偏低）
      月固定支出：8000 + 4500×2 + 1500（水电估算）= 18,500
      月保本线：18,500 / 68.75% = 26,909 元
      日保本线：≈ 897 元
      你现在日均：800 元
      ━━━━━━━━━━━━━━━━━━━━
      诊断：日均差 12%，每月亏 2,900。但这不是关键。
      关键是——你三楼啊兄弟，三楼。
      旁边一楼是蜜雪，价格还比你低，你拿什么打？
      
      （匹配案例：cases/失败案例/002-七层奶茶大厦-长治.md）
      跟你最像的是长治那个七层奶茶大厦，那哥们儿日销 800 也是这水平，
      最后 90 万全埋进去。
      
      我的建议：别再投装修了，今天起把所有精力放在外卖和团购，
      给自己定一个月：流水冲不到 1500/天就果断转让。
      记住：你不是输在产品，你输在选址那一刻。
```

### 场景 2：360 度转一圈

```
用户：[拍了一段视频/几张照片]

skill：好，我给你过一遍清单【调用 skill/街景观察清单.md】

      🟢 同业浓度：周围 30 米内 5 家小吃 → 商圈活的
      🟡 门头宽度：约 1 米 → 偏窄，开外卖店凑合
      🔴 台阶数：3 级 → 进店阻碍，每级少 30% 转化
      🔴 转让招牌密度：可见 4 块转让 / 12 个店面 → 33% 死街预警
      🟢 阴阳街：朝南，白天有阳 → 阳街
      🟡 竞品：左边 50 米蜜雪冰城 → 你要做奶茶？建议绕道
      🔴 门前路况：车速估算 50+ 码 → 快车道，看得见进不来
      ━━━━━━━━━━━━━━━━━━━━
      综合评分：38/100（韭菜斩杀线以下）
      勇哥诊断：做不了。这个铺子至少给我看到 60 分以上再考虑。
```

## 设计哲学

1. **数据 > 直觉**：能用数字回答的问题，绝不用感觉
2. **劝退优先于鼓励**：99% 的咨询者最该听到的是"做不了"
3. **案例匹配 > 抽象建议**：让用户看到自己未来的样子，比说一万句道理有用
4. **勇哥风格不是 cosplay**：是一种"真心实意把人骂醒"的话术系统
5. **永远预设最坏情况**：因为来咨询的人通常已经是最坏情况了
