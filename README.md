一份用来构建 **「勇哥餐饮.skill」** 的开源语料库。把抖音/B站「勇哥餐饮创业说」（梁朝勇）数百场连麦中沉淀下来的**方法论、案例、金句、街景观察清单**，整理成结构化、可被 LLM/Skill 直接调用的 Markdown 知识库。

不是娱乐项目（虽然确实很乐）。**真正的目的是：让任何一个想开餐饮店的普通人，在掏钱之前，先被勇哥（的影分身）骂醒一次。**

---

## 它能干什么

- 🪞 **餐饮体检**：输入你店里的营业额、毛利率、房租、人工，**5 秒算出保本线**，告诉你"还有救还是关了吧"
- 🧭 **开店决策**：走完勇哥的"开店五步法"，用数据回答**要不要开 / 开在哪 / 开什么 / 投多少**
- 🏚️ **快招识别**：你只需说出"加盟品牌名 + 总部城市 + 加盟费"，立刻拿到一份**快招风险评分**
- 📸 **360 度转一圈**：上传/拍摄一段店门口街景，AI 用 12 个观察点逐一打分（门头宽度、台阶、阴阳街、转让密度、竞品环境……）
- 📚 **案例匹配**：你的情况像谁？是"脸盆姐"还是"七层奶茶大厦"？从 30+ 真实翻车案例里拉出最像你的那一个
- 🎤 **勇哥嘴替**：用勇哥的语气、节奏、口头禅给你诊断结论。该劝退就劝退，该骂就骂，该吸氧就吸氧

## 这是一个真正的 Skill

✅ **顶层 [`SKILL.md`](./SKILL.md)** —— 标准 YAML frontmatter，符合 Anthropic Agent Skills 规范
✅ **可执行工具** —— `tools/*.py` 三个零依赖 Python 脚本，模型可直接 shell 调用
✅ **结构化语料** —— `corpus/` 9 篇 + `cases/` 30+ 案例，可直接 RAG
✅ **状态机 + 风格** —— `skill/` 4 份 prompt 资源，对话流程已工程化

**支持的 Agent 框架**：
- Claude Skills（原生支持）
- Cursor / Codex / Cline（通过 .cursorrules 或 system prompt 加载 SKILL.md）
- Coze / Dify / 扣子（拷贝 SKILL.md 作为人设 + 工具脚本作为插件）
- 自研 Agent（按 SKILL.md 第 5–6 节装载资源）

> 详见 [快速接入](#快速接入到-agent)。

## 快速接入到 Agent

### Claude Skills（推荐）
```bash
# 把整个仓库作为一个 skill 包加载
git clone https://github.com/astro-wen/yongge-restaurant.skill
# 然后在 Claude Skills 配置中指向该目录
```
Claude 会自动读取顶层 `SKILL.md`，按 frontmatter 描述决定何时激活，并按需读取子文档。

### Cursor / Codex / Cline
把 `SKILL.md` 内容粘贴进 `.cursorrules` / `AGENTS.md` / `.clinerules`：
```bash
cp SKILL.md .cursorrules
# 或
cp SKILL.md AGENTS.md
```

### Coze / Dify / 扣子
- **人设**：复制 `SKILL.md` 全文作为 Bot 人设
- **知识库**：上传 `corpus/` + `cases/` 作为 RAG 文档
- **工具**：把 `tools/*.py` 包装成自定义插件

### 任意支持 OpenAI 兼容协议的 Agent
```python
import requests
with open("SKILL.md") as f:
    system_prompt = f.read()

resp = requests.post("/v1/chat/completions", json={
    "model": "claude-3-5-sonnet",
    "messages": [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": "我开了家奶茶店在县城综合体三楼，每天卖800"},
    ]
})
```

## 使用示例（设想中的 skill 交互）

### 场景 1：体检已开门店

```
用户：勇哥救救我，我开了家奶茶店在县城综合体三楼，每天卖 800

skill：（自动调用 corpus/02-诊断SOP.md 第一步）
       哥们儿你先告诉我几个数：
       1. 总共投了多少钱？哪儿来的？
       2. 月房租多少？人工几个人？
       3. 毛利率多少？（不知道就告诉我食材一天用多少钱）
       4. 旁边有没有蜜雪、瑞幸、霸王茶姬？

用户：投了 35 万，10 万贷款；房租 8000 一个月；2 个员工 4500 一个；
     毛利率不知道...食材一天用 250 左右；旁边一楼有蜜雪。

skill：等会儿我给你算一下。【调用 skill/保本线计算器.md】
      ━━━━━━━━━━━━━━━━━━━━
      你的毛利率：(800-250)/800 = 68.75%（饮品偏低）
      月固定支出：8000 + 4500×2 + 1500（水电估算）= 18,500
      月保本线：18,500 / 68.75% = 26,909 元
      日保本线：≈ 897 元
      你现在日均：800 元
      ━━━━━━━━━━━━━━━━━━━━
      诊断：日均差 12%，每月亏 2,900。但这不是关键。
      关键是——你三楼啊兄弟，三楼。
      旁边一楼是蜜雪，价格还比你低，你拿什么打？
      
      （匹配案例：cases/失败案例/002-七层奶茶大厦-长治.md）
      跟你最像的是长治那个七层奶茶大厦，那哥们儿日销 800 也是这水平，
      最后 90 万全埋进去。
      
      我的建议：别再投装修了，今天起把所有精力放在外卖和团购，
      给自己定一个月：流水冲不到 1500/天就果断转让。
      记住：你不是输在产品，你输在选址那一刻。
```

## 设计哲学

1. **数据 > 直觉**：能用数字回答的问题，绝不用感觉
2. **劝退优先于鼓励**：99% 的咨询者最该听到的是"做不了"
3. **案例匹配 > 抽象建议**：让用户看到自己未来的样子，比说一万句道理有用
4. **勇哥风格不是 cosplay**：是一种"真心实意把人骂醒"的话术系统
5. **永远预设最坏情况**：因为来咨询的人通常已经是最坏情况了
