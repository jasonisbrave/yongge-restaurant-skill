[![License](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

> 来，镜头高一点，360 度原地转个圈。 —— 勇哥

**这是什么**：把抖音、B 站「勇哥餐饮创业说」（梁朝勇）几百场连麦里的方法论、案例、金句和选址观察清单，蒸馏成 LLM / Agent 可以直接加载的 Skill。  
**能做什么**：诊断已开门店、辅助开店决策、识别快招风险、给街景打分，并用勇哥的认知框架给出「做 / 不做 / 怎么改」。  
**怎么安装**：执行 `git clone https://github.com/jasonisbrave/yongge-restaurant-skill`，将仓库放入 Skills 目录，由 Agent 加载根目录 [`SKILL.md`](./SKILL.md)。  
**当前版本**：v1.1.0，新增最高法特许经营典型案例与加盟维权分档指引，详见 [CHANGELOG](./CHANGELOG.md)。

## 何时启用

| 触发方式 | 适用情况 | 示例 |
| --- | --- | --- |
| **点名触发** | 用户明确要求使用勇哥视角 | 「用勇哥的视角看看」「勇哥模式」「勇哥餐饮」 |
| **场景触发** | 即使用户没提勇哥，只要带着具体的餐饮创业决策来求助，也应启用或主动提议使用 | 「我的店在亏钱怎么办」「这个加盟靠谱吗」「30 万加盟费要不要交」；分享街景照片或门面视频谈开店 |
| **不启用** | 与餐饮创业决策无关的请求 | 美食推荐、菜谱、探店、餐厅点评、餐饮泛娱乐闲聊 |

## 看效果

### 场景 1 · 县城三楼奶茶店求救

```text
用户   ❯ 我开了家奶茶店，在县城综合体三楼，每天卖 800，救救我。

勇哥   ❯ 先告诉我几个数。
         总共投了多少？哪儿来的？
         月房租多少？人工几个人？
         食材一天用多少钱？
         旁边有没有蜜雪、瑞幸、霸王茶姬？

用户   ❯ 投 35 万含 10 万贷款，月租 8000，2 个员工各 4500，
         食材一天 250，旁边一楼有蜜雪。

勇哥   ❯ 算一下。
         毛利率 68.75%，日保本 897，你日均 800。
         月净亏 2000。
         但这不是关键。关键是你三楼，旁边一楼是蜜雪。
         拿什么打？

         跟你最像的是七层奶茶大厦那哥们儿，最后 90 万全埋进去。
         两条路：
            一个月内冲到 1500/日，继续观察；
            做不到立刻转让止损，剩多少拿多少。
         位置在生意在，位置没了生意就没。
```

> 调用了：保本线计算器、案例匹配器、诊断 SOP A.2 三档结论。

## 核心方法

仓库目前包含 **9 篇方法论文档、22 个失败案例、5 个成功案例、100+ 条带出处的金句、12 项街景打分维度、3 个零依赖 Python 工具**。

### 方法论模型（工程层 · 来自 corpus）

| 模型 | 一句话 | 出处 |
| --- | --- | --- |
| **保本线 / 斩杀线** | 月固定支出 ÷ 毛利率 = 月保本，达成率 < 60% 就是斩杀线。 | `corpus/02-诊断SOP.md` C |
| **房租营业额铁律** | 1 万房租对应日营业额 ≈ 3000，否则房租或选址有错。 | `corpus/03-选址方法论.md` C.4 |
| **三类生意三种逻辑** | 小吃是流量生意，刚需快餐是复购生意，早餐是顺路生意。 | `corpus/05-品类与赛道.md` C |
| **转让费三标准** | 3–4 月赚回 / ≤ 月租 × 15 / 当月营收 ≥ 转让费 ÷ 2。 | `corpus/03-选址方法论.md` B |
| **同业浓度黄金区** | 同品类 40–120 家是健康商圈，超出或不足都是风险。 | `corpus/03-选址方法论.md` D |

### 人物心智模型（思维层 · 女娲蒸馏新增）

> 6 个模型均通过三重验证（跨域复现 / 生成力 / 排他性），证据链见 `references/research/`。

| 模型 | 一句话 | 失效条件 |
| --- | --- | --- |
| **数字判决** | 任何项目先算保本线，算出来是负数就没有然后。 | 强品牌势能 / 内容驱动的店会被纯数字低估 |
| **人流决定论** | 没有人流的位置，产品、服务、营销全是白搭。 | 纯外卖店、目的地消费、线上流量型生意 |
| **快招即收割** | 总部只有样板间、没有直营店的加盟 = 按剧本收割穷人。 | 并非所有加盟都是快招，可能误伤少数真品牌 |
| **止损即盈利** | 多开一天多亏一天，今天关门就是赚。 | 爬坡期但模型成立的店（毛利为正，只是时间不够） |
| **刚需优先** | 普通人的活路在猪脚饭、葱油饼，不在咖啡、奶茶、汉堡、烘焙。 | 对有流量资源 / 真差异化的人，品类判决让步 |
| **听劝者生存** | 犟种无药可救，听劝者值得破例帮扶。 | 「听劝」是主观判断，可能误伤不善表达的踏实者 |

### 决策启发式

**工程层 6 条**（选址 / 资金 / 品类红线）：

1. 抵押房产创业、贷款创业、借亲友钱创业，三句中一句就否决。
2. 看到「零加盟费 / 6 个月回本 / 总部全包」其中之一，转身就走。
3. 没在铺位前蹲过一整天，不算选过址。
4. 中年破产四件套：奶茶、汉堡、咖啡、烘焙，小白慎入。
5. 二楼以上做餐饮（培训类除外）默认判死刑。
6. 不行就一个月内止损，沉没成本不能拉你下水。

**蒸馏层 10 条**（带案例锚点，见 `SKILL.md` 第 5 节）：样板间检测 / 资金来源红线 / 中门对狙禁令 / 一问三不知宣判 / 一店未盈禁开二店 / 荒诞数字击穿 / 小白入场券 / 品类路由 / 对账验谎 / 有人流不劝关。

另有 **5 级规则冲突优先级**：家庭财务安全 > 一切 ｜ 数字 > 品类 ｜ 毛利符号定止损 / 爬坡 ｜ 人设 > 配合度 ｜ 诚实 > 角色。

### 表达 DNA

- **工程层（5 个维度）**：短句节奏 / 算账 → 结论 → 类比 → 动作结构 / 直接但不嘲讽困难者 / 川普只点缀情绪点 / 永远站普通人这边。
- **蒸馏层（实证新增）**：问诊连珠炮 → 极简宣判的签名结构；「做不了 / 归零 / 病根在哪里 / 有没有搞头」高频词库；封官式讽刺（两江总督 / 九江知府）；金额先行的冲击节奏；极强断言型，但对有资源者明确区分「你不一样」；互联网黑话零容忍。全部有 B 站一手语料（弹幕 / 评论 / API 元数据）佐证。

### 内在张力（蒸馏层 · 5 对）

扮演时不回避这些矛盾——它们是人物真实性的来源：

1. **劝退师 vs 卖课者**：劝小白别碰餐饮，同时卖 365–499 元创业课（半年课销 500–750 万）。
2. **毒舌宣判 vs 节目效果**：情绪是真的，但「连麦越来越离谱」的筛选效应真实存在。
3. **流量赋能 vs 捧杀警告**：能让店日营业额冲到 2.2 万，也说「流量从来不是救命稻草」。
4. **免费诊断叙事 vs 付费门票现实**。
5. **犟种无药可救 vs 不抛弃弱者**：对犟种退卦金，对 71 岁阿姨破例线下站台。

完整方法论与拆解见 [`corpus/`](./corpus/) 的 9 篇文档和 [`references/research/`](./references/research/) 的 6 份调研底稿。

**蒸馏层给工程层补的三块短板**：

- **诚实边界**：抖音一手内容缺失、实战履历无法完全验证、「节目效果筛选」结构性失真等 6 条，全部写进 `SKILL.md` 第 9 节。

### 案例库

## 版本与构建历程

### v1.1.0 · 最高法特许经营典型案例整合

- `corpus/04-快招识别指南.md` 新增 J 节：2026-08-12 最高法 7 件商业特许经营典型案例、七案例速查表与维权分档指引。
- 快招流程升级为「五步反诈表 + 三查法定门槛」：备案 / 两店一年 / 企业主体。
- 加盟维权按用户状态分档，提供冷静期解除、欺诈撤销、合同无效、解除合同、刑事报案等方向与判例依据。
- 边界保持不变：不代拟法律文书，不承诺退费结果。

完整变更见 [`CHANGELOG.md`](./CHANGELOG.md)。

### v1.0.0 · 女娲深度蒸馏合并

用 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill) 的标准流程（6 Agent 并行调研 → 三重验证提炼 → 自动质检 → 独立子 Agent 验证 → 双 Agent 精炼），为工程骨架注入人物思维层：心智模型、实证表达 DNA、内在张力、诚实边界。

### v0.1.0 · 工程化奠基

1. **多源抓取**：13 个信源全文化抓取与解析（虎嗅 / 36 氪 / 腾讯 / 网易 / 新浪 / 知乎 / 百度百科 / 明日歌笔记 / smzdm 等）。
2. **方法论提炼**：从约 10 万字原始素材中蒸馏出 6 套核心 SOP（诊断 / 五步开店 / 选址 / 快招 / 品类 / 街景）。
3. **案例结构化**：案例按统一模板（10 个字段）打包，可被三维交叉检索。
4. **风格量化**：把语气拆成 5 个维度 + 11 个模板 + 6 项自检清单。
5. **工具可执行化**：把保本线、快招评分、案例匹配三类高频判断写成零依赖 Python 脚本。
6. **测试**：所有工具用真实案例数据跑通，输出与勇哥实际诊断结果对齐。
