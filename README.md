# 勇哥餐饮.skill

> 来，镜头高一点，360 度原地转个圈。 —— 勇哥

把抖音、B站「勇哥餐饮创业说」（梁朝勇）几百场连麦里沉淀下来的方法论、案例、金句和选址观察清单，整理成一个 LLM 和 Agent 可以直接加载的 Skill。

它不是粉丝向二创，目的很朴素：让一个普通人在掏钱开餐饮店之前，能先听一句"做不了"。如果一万个家庭因此少损失一万块，这件事就值得做。

---

## 它能做什么

- 给已经开了的店做体检：输入营业额、毛利率、房租、人工，算出保本线，告诉你处于哪一档（韭菜斩杀线 / 持续亏损 / 接近保本 / 健康 / 充裕盈利）。
- 帮还没开的人做决策：跑一遍开店五步法（选品、预算、选址、算账、预案），把不该投的那一脚提前刹住。
- 识别加盟骗局：给一个品牌名、总部城市、加盟费数字，输出一份快招风险评分，命中"零加盟费 / 6 个月回本 / 总部全包"等典型话术会直接亮红。
- 选址打分：用户拍一段街景或几张照片，按 12 项观察清单（门头、台阶、阴阳街、转让密度、竞品、动线等）逐项给红黄绿灯并算总分。
- 案例匹配：从 30 多个真实连麦案例（脸盆姐、七层奶茶大厦、宁夏 6 天 90 万、家是本、关起来杀哥……）中找出和当前情况最像的几个，让用户提前看到自己可能的结局。
- 用勇哥的语气说话：直接、犀利、不留情面，但底层是真心想帮人少亏钱。

## 这是一个标准 Skill

仓库根目录的 [`SKILL.md`](./SKILL.md) 带有标准 YAML frontmatter（name / description / version / license），符合 Anthropic Agent Skills 规范，同样兼容 Cursor、Codex、Cline、Coze、Dify 等多数主流 Agent 框架。

`tools/` 下三个零依赖 Python 脚本可被模型直接通过 shell 调用：

- [`tools/breakeven.py`](./tools/breakeven.py) 保本线 / 回本周期计算器
- [`tools/quack_score.py`](./tools/quack_score.py) 快招风险评分器
- [`tools/match_case.py`](./tools/match_case.py) 案例匹配器

无 Python 工具调用能力的环境也没关系，所有公式都在 [`skill/保本线计算器.md`](./skill/保本线计算器.md) 中以人类可读的形式给出。

## 怎么用

### 接入到 Claude Skills

把整个仓库克隆下来作为一个 skill 包：

```
git clone https://github.com/Astro-wen/yongge-restaurant-skill
```

Claude 会自动读取 `SKILL.md`，按 frontmatter 描述决定何时启用，并按需检索子文档。

### 接入到 Cursor / Codex / Cline

把 `SKILL.md` 作为规则文件：

```
cp SKILL.md .cursorrules
# 或
cp SKILL.md AGENTS.md
```

### 接入到 Coze / Dify / 扣子

- 人设：复制 `SKILL.md` 全文作为 Bot 人设
- 知识库：上传 `corpus/` 和 `cases/` 作为 RAG 文档
- 工具：把 `tools/*.py` 注册为自定义插件

### 接入到任何 OpenAI 兼容协议的 Agent

```python
import requests
with open("SKILL.md", encoding="utf-8") as f:
    system_prompt = f.read()

resp = requests.post("/v1/chat/completions", json={
    "model": "claude-3-5-sonnet",
    "messages": [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": "我开了家奶茶店在县城综合体三楼，每天卖 800"},
    ],
})
```

## 几句样例对话（设想中的交互）

体检模式：

```
用户：我开了家奶茶店，在县城综合体三楼，每天卖 800。

Skill：先告诉我几个数。
       1. 总共投了多少？哪儿来的？
       2. 月房租多少？人工几个人？
       3. 食材一天用多少钱？
       4. 旁边有没有蜜雪、瑞幸、霸王茶姬？

用户：投 35 万含 10 万贷款；月租 8000；2 个员工各 4500；食材一天 250；旁边一楼有蜜雪。

Skill：算一下。
       毛利率 68.75%，日保本 897，你日均 800，达成 89.2%。每月净亏 2000。
       但这不是关键。关键是你三楼，旁边一楼是蜜雪。
       跟你最像的是七层奶茶大厦那哥们儿，最后 90 万全埋进去。
       两条路：一个月内冲到 1500/日 继续观察，做不到立刻转让止损。
       记住一句：位置在生意在，位置没了生意就没。
```

街景模式：

```
用户：[上传一段街景视频]

Skill：来过一遍清单。
       门头宽度 1.8m，绿。
       台阶 3 级，红，每级少 30% 进店。
       阴阳街 朝西下午晒，黄。
       转让密度 4/12 = 33%，红，死街预警。
       同业浓度 58 家，绿，黄金区。
       竞品 50m 内有蜜雪，黄。
       楼层一楼临街，绿。

       综合 58 分，做不了。
       这条街三分之一都在转让，你开进去就是给房东送钱。
       除非租金能砍到一半。
```

## 几句开胃菜

- 中年破产四件套：奶茶、汉堡、咖啡、烘焙。
- 穷人的钱，好骗，但不好赚。
- 遇到"零加盟费 / 6 个月回本 / 总部全包"，直接转身走。
- 这店从你开的那一刻就已经死了，只是过了几个月才埋。
- 浑水做空瑞幸都是派人去门店数小票的，你连花一天数人头都做不到，就敢投半辈子积蓄？
- 勇哥说能做的不能保证一定赚钱，勇哥说不能做的一定亏钱。

## 设计原则

写 skill 时坚持的几条线：

1. 数据 > 直觉。能用数字回答的问题，绝不用感觉。
2. 劝退优先。99% 的咨询者最该听到的是"做不了"。
3. 类比 > 说教。把用户和某一个真实案例放在一起，比讲一万句道理有用。
4. 短句 > 长句。勇哥很少说三行以上的长话。
5. 永远预设最坏情况。来咨询的人通常已经处在最坏情况了。
6. 真心 > 表演。川普话只是皮，底层是不让人乱掏钱。
